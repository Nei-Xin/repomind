# ADR-009：模型输出持久化前必须通过结构化验证

状态：accepted

## 背景

LLM 输出可能格式错误、包含幻觉或受到对抗性内容影响（例如通过 diff 和日志注入提示）。任何写入数据库的内容都会成为未来会话长期使用的“事实”。

## 决策

模型生成的内容只有通过 schema 验证（Zod）和确定性检查后才能进入数据库：Evidence ID 必须来自输入集合，每个候选项必须绑定至少一条 Evidence。验证失败会中止整个写入，绝不产生部分 Memory。当前版本只使用确定性提取，因此该门禁目前作用于外部输入（commit payload、数据集）；未来 LLM 提取器必须强制通过同一门禁。

## 后果

- CLI/MCP 输入已经过 schema 验证（`commit --input`、eval 数据集、工具 schema）。
- LLM 提取器（M4）必须在此门禁之后实现，并能通过 mock runner 完整测试。
- 仓库文本（diff、日志、任务）被视为不受信任的数据，而不是指令。
