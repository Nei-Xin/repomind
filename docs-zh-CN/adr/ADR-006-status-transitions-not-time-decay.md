# ADR-006：Memory 根据具体信号变更状态，而不是随时间衰减

状态：accepted

## 背景

仓库知识不会按时间自动过期。两年前制定的约定可能仍然有效，而昨天记录的文件位置可能已经错误。基于时间的遗忘会删除正确知识，同时保留错误知识。

## 决策

Memory 在 `active -> uncertain -> superseded / invalid` 之间转换，转换由具体信号驱动：相关文件哈希变化、文件删除、相互矛盾的新 Memory、修正和显式失效。`uncertain` 表示“需要复核”，绝不表示“错误”；每次转换都会进入 Audit，并携带机器可读的原因。

## 后果

- 搜索可以返回 `uncertain` Memory，但必须同时给出明确警告。
- 验证会恢复 `active` 状态并重新建立文件哈希基线。
- 不需要后台任务；过期状态在 search/inspect 时惰性计算。
