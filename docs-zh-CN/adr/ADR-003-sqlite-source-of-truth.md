# ADR-003：SQLite 是本地事实来源

状态：accepted

## 背景

单用户版本在本地保存全部 Memory、Evidence、Session 和 Audit 历史。它需要事务、迁移、FTS 和未来的向量索引，同时不能依赖服务器进程。

## 决策

每个项目使用一个 SQLite 数据库（通过 `node:sqlite`），启用 WAL 和外键，采用版本化迁移，并且每个进程只使用一个连接。FTS5 和未来的任何向量索引都是可从基础表重建的派生数据。

## 后果

- 任何跨表写入路径都必须在同一个事务中执行。
- `node:sqlite` 要求 Node.js 22.5 或更高版本。
- 派生索引（FTS、向量）绝不能成为任何事实的唯一副本。
